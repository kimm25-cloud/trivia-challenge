# Project Context

- This is a Team Trivia Challenge prototype.
- It is frontend-only; do not add a backend or database.
- Requirements are defined in `specs/PRD.md`.

# Build and Test

- No build step is required. Open `app/index.html` in a browser.
- Test all interactive features, including answering, feedback, scoring, results, persistence, replay, and responsive layout.
- Use **Play again** (the prototype's reset control) to restore the quiz state and sample questions.

# Coding Standards

- Use vanilla JavaScript only; do not add frameworks.
- Keep all application code in `app/index.html`.
- Follow `.github/copilot-instructions.md`.

# What Not to Do

- Do not add backend services.
- Do not add authentication.
- Do not install packages.
